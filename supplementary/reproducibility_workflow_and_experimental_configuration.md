# Supplementary Material: Reproducibility Workflow and Experimental Configuration

## S1. Dataset access and governance

The public development experiments use the TCIA Osteosarcoma Tumor Assessment dataset and the Kaggle Bone Tumor Classification dataset. These datasets are not redistributed in this repository. The Hitit University Faculty of Medicine cohort is restricted and is not publicly released.

## S2. Input organization

The expected input organization is documented in `data/README.md` and `data/manifest_template.csv`.

## S3. Histopathology preprocessing

Histopathology tiles are resized to 224 × 224 pixels. Macenko stain normalization is supported through the preprocessing interface. Training-time augmentation is applied only to training samples.

## S4. Radiograph preprocessing

Radiographs are resized to 224 × 224 pixels and min-max normalized. Training-time augmentation is applied only during training.

## S5. Split definitions

P001 and P002 are used for development training, P003 for validation/calibration, and P004 for primary held-out testing. Leave-one-patient-out folds can be generated by repeating the workflow with each TCIA patient held out.

## S6. Model configuration

Both branches use EfficientNet-B0 initialized with ImageNet weights. The last two feature blocks and classifier head are trainable. The histopathology head has three outputs. The radiograph head has two outputs.

## S7. Probability extraction

Frozen branch outputs are written to CSV files. Fusion operates on these probability files rather than paired raw images.

## S8. Radiograph probability remapping

Binary radiograph probabilities are remapped into the three-class histopathology space using the rule documented in the manuscript and repository.

## S9. Adaptive gating fusion

The gate is a 6-128-64-1 MLP with sigmoid output. It receives `[p_r ; p_h]` and predicts the sample-specific radiograph-branch weight.

## S10. Baseline models

The repository includes fixed-alpha fusion, max-confidence selection, XGBoost, logistic regression, linear SVM, shallow MLP, and confidence-attention late fusion baselines.

## S11. Evaluation metrics

Accuracy, macro precision, macro recall, macro F1, macro AUROC, calibration error, Brier score, and McNemar testing are implemented in `src/evaluation/`.

## S12. External Hitit cohort interface

The interface is provided for authorized local evaluation only. No raw Hitit images, patient identifiers, or private metadata are included.
